I want to create a mobile app inspired by the anime Solo Leveling, where the protagonist receives daily missions from a mysterious “System” that helps him grow stronger.

In the same spirit, this app should serve as a spiritual leveling system for Muslims, where the “System” assigns five essential daily prayer tasks:

Fajr

Dhuhr

Asr

Maghrib

Isha

🎯 Core Functionality Each prayer completed is logged and adds XP to the user’s spiritual “Level,” visualized through ranks (e.g., Bronze ➝ Silver ➝ Gold ➝ Diamond).

The tasks reset daily, just like quests in Solo Leveling.

❌ Penalty System (Accountability Mode) If the user misses 1 prayer, the app automatically blocks all social media apps (e.g., Instagram, TikTok, YouTube, Facebook), while WhatsApp remains accessible.

If the user misses 2 or more prayers, the app blocks both games and social media, again only allowing WhatsApp.

Punishment carries over to the next day if the user fails to complete tasks.

✅ Verification & Parental Approval Prayer completion must be verified by a parent or guardian. The app sends a “Yes/No” prompt to the parent’s phone for each prayer.

The user's level progression and app access depend on verified responses.

🔐 App Control & Enforcement The app should integrate with the device’s system (via Android’s Digital Wellbeing API or similar) to enforce app restrictions, making it impossible to bypass.

The app itself can temporarily disable or block itself if too many tasks are missed, adding a real consequence like the “System” giving punishments in Solo Leveling.

🧠 Goal To motivate consistent prayer through a powerful gamified accountability system that blends faith, discipline, and anime-style progression, helping young Muslims build habits like a true “Hunter” of righteousness.
